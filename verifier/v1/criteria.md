# Verifier v1 — 验收标准(源自需求.txt)

## A. 六家生成能力(页面点击验证,禁止命令行打生成接口)
对每家供应商(Civitai / Fal / HuggingFace / 魔搭AI / 魔搭CN / NanoGPT):
- A1 文生图: 页面填参 → 点生成 → 出图
- A2 图生图: 页面传参考图 → 点生成 → 出图
- A3 图生视频: 页面传参考图 → 点生成 → 出视频
- A4 生成物落盘本地,卡片上可见
- 通过标准: 每家至少 A1 走通;A2/A3 若该家官方确实无此能力,须页面明示原因(不许装死/报错糊弄)

## B. 参数能力与官方一致(铁律)
- B1 官方支持的参数(LoRA、seed、CFG、steps、宽高、negative、metadata)页面必须可输入
- B2 参数真实进入请求体(抓包/日志核对),不许 UI 摆设

## C. 模型 / LoRA 搜索
- C1 模型选择器支持搜索
- C2 LoRA 选择器支持搜索
- C3 LoRA 列表按当前底模过滤/匹配,不许出现底模不兼容的 LoRA 冒充可用

## D. Civitai 帖子智能匹配
- D1 贴链接/图ID → 原 prompt、负面、底模、LoRA(含权重)、宽高、步数、CFG、种子全部摊开上屏,不许缩写
- D2 在【当前选中的一家】内匹配模型,匹配不到就明说,不许偷换别家、不许跳回 Fal/Civitai、不许套写死默认(Krea2 等)
- D3 帖子是 SDXL 底模时,页面模型必须对到 SDXL 家族或明示无匹配,不许显示 Krea2 还说「已智能匹配」
- D4 六家都要支持该导入匹配流程(不只是 Civitai 自己家)

## E. 持久化
- E1 生成完成后硬刷新页面,图/视频仍在原卡片上

## F. 画布体验(Seko 复刻)
- F1 无限画布: 平移/缩放/点阵背景
- F2 节点卡片 + 连线
- F3 只完善不删功能、不藏功能

## G. 测试纪律
- G1 每次测试 prompt 不重复
- G2 导入原帖完整参数,不许自编短词冒充
- G3 该家没有对应 LoRA 时: 换该家支持的参数或换一张原图,不许发明默认值
- G4 验收对照原站画面,不裁图充数

## 验证方式
- 本地起服务,playwright 驱动页面点击(模拟真实用户)
- 每次运行记录到 verifier/runs/<timestamp>.md(命令、exit code、产出值)
